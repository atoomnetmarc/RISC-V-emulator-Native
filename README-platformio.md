# PlatformIO

Builds the emulator as a native executable via the
[PlatformIO Native platform](https://docs.platformio.org/en/latest/platforms/native.html).

## Build

```
pio run -e RV32I
```

Binary: `binaries/gcc/<env>`, listing: `.pio/build/<env>/program.lss`.

## ISA extension combination matrix

[platformio_isa-extension-combination_env.ini](platformio_isa-extension-combination_env.ini) is generated by
[generate-isa-extension-combination.py](generate-isa-extension-combination.py): a strength-4 covering array
plus singles by default, `--full` for exhaustive. Envs marked `# smoke` are
selected by RISC-V-emulator-ACT's `test_all.sh --smoke`. Regenerate with:

```
python3 generate-isa-extension-combination.py --ini platformio_isa-extension-combination_env.ini
```

Compiler is the system default (`cc`); for other compilers use the
[CMake driver](README-cmake.md).
